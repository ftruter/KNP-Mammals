# Lessons from KNP-birds, for KNP-Mammals

Snapshot of https://github.com/ftruter/KNP-birds (`main` at `a650569d`, 12 Nov 2026, after PR #187) and live site https://birds.truter.world. Canonical agent handoff is the repo's `STATE.md` (newer than the 10 Nov copy at `/workspace/knp-birds/STATE.md`). Only facts found in those sources are stated below.

## Features

Open field guide to Kruger National Park and bordering Marloth Park: **493 species in 86 families** (residents, regular migrants and regular visitors; rare vagrants out). Names follow IOC / BirdLife South Africa 2026 (`README.md`, `docs/species-sources.md`).

- Species pages: English, Afrikaans and scientific names; summary; habitat; months present; residency; length; structured plumage `variants` (age/sex/season); six on-page comparisons derived by diffing marks, not stored prose (chick/juvenile vs adult, winter vs summer, male vs female, flight above vs below, perched front/back/side, male vs female calls); photographs with zoom and a closed "Credit: X" disclosure; playable calls; similar species; cited population estimate (`docs/schema.md`, PRs #161, #162, #164).
- Family pages with up to three iconic species (highest mature-individual midpoints), all-season totals, and seasonal figures that can be Unknown or partial (`docs/schema.md`; PR #143).
- Indexes: `/species`, `/families`, `/credits`, `/vocab/colours`, `/sitemap` and `/sitemap.xml`, header search and `/search` (PR #148).
- Identify by photo (`/identify/photo`, issue 151 / PRs #155, #159, #186, #187): on-device MobileNetV4, 493 classes. A second, smaller model, EfficientDet-Lite0, finds the bird and the page crops to the largest box automatically (issue 180 / PR #186); the crop is shown beside each result, "Change the crop" opens the crop view on that square, and if no bird is found the crop view opens as before, with a line saying so. "Another bird in this photo" cycles through other boxes that score at least 0.5. Live mode ("Live: name birds as you point") is offered only when the detector is loaded and the browser has `getUserMedia` (issue 181 / PR #187): the camera is shown in the page, the bird is outlined, and a name (with a link) appears under the video; "Hold" freezes the frame, releases the camera, and runs the ordinary photo path; it also stops when the page is hidden, when the camera track ends, after 60 seconds with no bird in view, and when three frames in a row each take over a second. Quoted download is 24.6 MiB (9.3 MiB recogniser + 4.4 MiB detector + 10.9 MiB runtime). The detector is optional: a visitor who already has the recogniser is offered it (`#identify-upgrade`), not sent it unasked; in the installed app it is part of the "Photo recognition model" option and shows as an update. Issue #181 is still open pending phone tests. Identify by sound (`/identify/sound`, issue 150 / PRs #152, #153): on-device BirdNET V2.4; covers 362 of 493 species. Live listen mode analyses the newest 3 s once a second (issue 179 / PR #185). Home leads with these two actions (PR #167).
- Installable web app with a six-option download panel (issue 157 / PR #175). Public ARD manifest and a read-only MCP `search` tool (`README.md`, `docs/ard.md`). Code Apache-2.0; media keep their own licences; site is non-commercial (`README.md`).

## Architecture and data model

Cloudflare Worker `src/worker.js` + `wrangler.toml` (`name = "knp-birds"`, `account_id` present). Binding `BIRDS_KV` holds JSON; binding `IMAGES` is R2 bucket `knp-birds-images` (photos, cleaned audio, models, offline copies). Custom domain `birds.truter.world`. Workers Caching is on. Deploy on `main`: `pnpm install --frozen-lockfile`, then `npm run deploy` (dashboard left on npm on purpose). That uploads `data/` to KV, then deploys with `DATA_VERSION` and `DATA_PUBLISHED_AT`. Models (`pnpm run models:publish`) and offline media (`pnpm run media:publish`) are separate, token-gated steps; until they run, identify downloads fail and offline media says "not available yet" (`README.md`, `STATE.md`).

One KV key, three formats: no extension HTML, `.md` Markdown for agents, `.json` the stored document. Slug = scientific name, lowercase, spaces to hyphens. Keys: `species/<slug>`, `family/<slug>`, `index/species|families|credits|identify-sound|identify-photo|offline`, `vocab/colours`. Other routes include `/`, `/search`, `/sitemap.xml`, `/images/<key>`, `/audio/<key>`, `/models/<version>/<file>`, `/.well-known/ard.json`, `POST /mcp`, `/manifest.webmanifest`, `/sw.js`, `/offline.json`. Server-rendered; first-party JS only (`src/client`); CSP `script-src 'self'`; must work with JS off.

Species fields (see `docs/schema.md`, `docs/content.schema.json`): `commonNames.en` / optional `.af`, `family`, optional `status` (`resident`, `intra-african-migrant`, `palearctic-migrant`), optional `size.lengthCm` `{min,max}`, `summary`, `sampleData`, `monthsPresent`, `habitat`, `similar`, `sources`, `variants` with controlled colours from `data/vocab/colours.json`, `viewNotes`, `calls`, `images` (`key`, `fileUrl`, `hosted`, `author`, `license`, `licenceUrl`, `aiGenerated`, view/age/sex/season), `population` (Kemp range or later survey; never invent), optional `research`. Calls prose stays in the species file; chosen recording, grade and edit note are merged from `data/audio/recordings.json` (`docs/audio.md`). `scripts/seed.mjs` derives family `species`, `iconicSpecies`, `population`, `residency`, and the indexes; those files are not edited by hand.

Photo model `knp-photo-1-mnv4m-288-int8` (9.3 MiB int8 TFLite, 288 px): 180,892 iNaturalist photos, 82.3% top-1 / 92.2% top-3 / 92.4% family on 5,889 held-out photos; weights CC BY-NC-SA 4.0; published to R2 and https://huggingface.co/FTruter/knp-birds-photo. The site never fetches Hugging Face (`docs/identify-photo-model.md`). A second on-device model, Google's EfficientDet-Lite0 (COCO, Apache 2.0), 4,562,456 bytes (4.4 MiB), lives in `models/efficientdet-lite0-coco-raw-1/` with constants in `PHOTO_DETECTOR` in `src/identify.js` (`version`, `file: bird-detector.tflite`, `inputSize: 320`, `sha256`, `birdClass: 15`, `score: 0.3`, `overlap: 0.5`, `margin: 0.35`, `another: 0.5`); it is not trained in this repo (`docs/identify-photo-model.md`; `training/identify-photo/README.md` steps 10–12). The shipped file is not Google's file byte for byte: LiteRT.js cannot run the last step (`TFLite_Detection_PostProcess`: variable-size outputs fail with "Insufficient buffer size"), so `training/identify-photo/strip-detector.py` removes that step only and the page picks boxes itself (`anchorBox`, `birdBoxes` in `src/client/identify-photo.js`); weights are unchanged (PR #186; `STATE.md`; `docs/identify-photo-model.md`). The detector is optional everywhere: the recogniser still loads without it. `pnpm run models:publish -- --only photo` now also uploads the detector and needs `data/models/bird-detector.tflite` (or `--photo-detector`); the detector is not republished on Hugging Face (`scripts/publish-models.mjs`; `docs/identify-photo-model.md`). `STATE.md` at `main` still says: "Not published yet: run `pnpm run models:publish -- --only photo` before deploying." Until then the page loads the recogniser, finds no detector, and works as it did before, with an offer to download the detector that fails (PR #186 "Before deploying"). Only the HTML of `/identify/photo` sends `Permissions-Policy: camera=(self), microphone=(), geolocation=()` (`PHOTO_PERMISSIONS` in `src/respond.js`, `camera: true` on `PHOTO_PAGE` in `src/site.js`); the CSP is unchanged (the video plays from a stream object, not a `blob:` URL); the sound page still has no camera (PR #187; `STATE.md`; `src/static.js`). Sound uses official BirdNET V2.4 via LiteRT.js (~37 MB with runtime); label map in `data/identify/birdnet-labels.json` plus hand-checked `birdnet-synonyms.json`; copy at https://huggingface.co/FTruter/knp-birds-sound (`docs/identify-sound-spike.md`).

## Sources that worked, ranked, and their licences

Ranked for species *research* in repo `STATE.md` (URL patterns there):

1. Newman's Birds — primary plumage, length, voice, residency. Licence not stated in the files read.
2. xeno-canto — calls; API v3 needs `XENO_CANTO_API_KEY`. Accepted: CC0, CC BY, BY-SA, BY-NC, BY-NC-SA, and ND variants (ND may be linked only, never played or edited) (`docs/audio.md`).
3. iNaturalist — preferred photographs, Kruger first; also the photo-training corpus (CC BY-NC majority, plus CC BY, CC0, CC BY-SA, CC BY-NC-SA; no ND / all-rights-reserved).
4. Wikimedia Commons — second photo source.
5. SABAP1 species texts — residency and habitat when Newman is thin.
6. Avibase Kruger checklist — rare vs regular (`region=ZA000003`). Direct fetches often HTTP 403 (`docs/families-sources.md`).
7. Wikipedia — only when Newman has no page; text is CC BY-SA 4.0. Do not invent colours or lengths the article does not give.
8. BirdLife South Africa 2026 checklist and Birda / SABAP2 Kruger checklist — the family and species lists themselves (`docs/families-sources.md`, `docs/species-sources.md`). Inclusion: SABAP2 Kruger count ≥ 3, not BLSA vagrant with count < 30, not introduced/data-error. Taxonomy remaps from outdated Birda names to BLSA 2026 are tabulated in `docs/species-sources.md` (do not invent; record the remap).
9. Kemp et al. 2001 — population only, already applied (453 named rows; 40 species have a null estimate; 4 later park surveys sit on `kempBaseline`). Cite the journal PDF; **never host or quote the appendix**. Article licence left unknown on `/credits` (`docs/population-sources.md`).

Afrikaans family headings: Waterberg Bioquest Voëls; leave `af` null rather than invent a group name (`docs/families-sources.md`). SANParks HTML/PDF also 403'd from the research environment. Photo training needed CC BY-NC or 88 (spike) / 78 (permissive rerun) species stay too thin; owner dropped the CC0+CC BY-only model on 12 Nov 2026 (`docs/identify-photo-spike.md`, `docs/identify-photo-model.md`). BirdNET: treat as CC BY-NC-SA 4.0 (Zenodo metadata says BY-NC; docs say BY-NC-SA).

## Rules and gotchas

- Never fabricate data. Omit `size` and `status` rather than invent them. Never change population or Kemp figures. `null` on a field mark means "not recorded", not "uncoloured". Record gaps in `research.note`. Grep the data; do not trust a memorised list (`STATE.md`).
- Newman or spreadsheet lengths can appear as `#VALUE!`. Never store that string; family tests reject it.
- Display/edit licences: CC0, CC BY, CC BY-SA, CC BY-NC and SA variants. Never ND for a displayed or edited file. Prefer Kruger photos, then the rest of South Africa. Clean a recording only when the best file is grade C or worse and the licence allows derivatives; keep the original recordist and licence; do not claim a filter until `hosted` is set. Grade A slots are not replaced. Sexed call slots are filled by hand (`docs/audio.md`).
- Only [@ftruter](https://github.com/ftruter) may approve or merge PRs. Agents must not merge. Check with the owner before anything that costs money. Do not commit the Kemp PDF.
- One pull request per family. Branch from latest `main`. Do not stack on an open sibling once the owner squash-merges (GitHub retargets the child and it often becomes dirty). Confirm `mergeable: true` and `mergeable_state: clean` before asking for a merge (`STATE.md` Gotchas). The 10 Nov merge wave (#72–#105, then length/photo gap PRs) produced many "merge main into child" commits.
- Workers Builds: pnpm 9 rejected an empty workspace file (PR #154); deploy command must stay `npm run deploy` (PR #173). Cache keys must include `DATA_VERSION` and the Worker version or a data-only KV write serves stale HTML (`README.md`).
- Photo training: backbone learning rate near 0.00005; 0.001 destroys pretrained weights and scores at chance (`STATE.md`, `docs/identify-photo-spike.md`). Never guess BirdNET (or iNaturalist) mappings; 123 bird species are not in BirdNET and 8 have only a broader label (`docs/identify-sound-spike.md`). Trust a copied media file's bytes over a wrong label (commit `aa1abc98`). iOS benches must be served over HTTPS (plain HTTP was 25–40× slower).
- LiteRT.js cannot run a stock EfficientDet-Lite file: the last op, `TFLite_Detection_PostProcess`, has outputs of no fixed size and fails with "Insufficient buffer size". Strip that step and pick boxes in the page (`strip-detector.py`; PR #186; `STATE.md`; `docs/identify-photo-model.md`).
- Do not crop tightly around the animal: the recogniser was trained on photos with some surroundings. Margin 0 is worse than the middle-88% baseline; 35% margin at score 0.3 was chosen as the middle of a flat range (`docs/identify-photo-model.md`).
- Do not ship a larger detector without phone evidence: EfficientDet-Lite2 gains only 0.3 points on species first for 2.8 MiB more download and about twice the work (Google's published phone figures cited in the model card: 36 ms vs 69 ms). Lite0 was kept; Lite2 is documented as a drop-in if phone photos show that small birds are missed too often (`docs/identify-photo-model.md`; PR #186).
- Do not force an extra model download on existing visitors: they already have the recogniser cached. The page offers the detector (`#identify-upgrade`); the installed-app photo-model option shows as an update (PR #186; `STATE.md`).
- Held-out iNaturalist / web photos understate the hard case: the test photos are at most 500 pixels on the longer side and mostly already framed on the bird. A distant bird in a 12-megapixel phone photo is where the detector will miss most; it sees the whole photo at 320 pixels (`STATE.md`; `docs/identify-photo-model.md` "What was not measured"; PR #186 "Not verified").
- Do not close an issue from the implementing PR when its "Done when" still needs real-device or tester checks. PR #187 left #181 open because the phone checks were still outstanding (`STATE.md`; PR #187).
- Announce a changing live name once in a status line ("Seen: <name>."), not as a live region; keep a text line for whether a bird is in view so the mode does not depend on seeing the outline (`STATE.md`; PR #187; issue 181).
- Keep the phone's own camera app as the zoom fallback: Live cannot zoom as far, and the zoom slider is shown only when `track.getCapabilities().zoom` exists, otherwise a note tells the visitor to take a photo (`LIVE_NOTE` in `src/identify-photo-page.js`; PR #187).
- README "Status" still says research will follow, which is stale once all 493 documents are sourced (`STATE.md`).

## Process lessons

- Do the first family (or the first list) carefully as a pro forma, then one short-lived session / one PR per remaining family. `STATE.md` Gotchas: "Prefer a lean, short-lived session. Do not hand work to a long-lived cloud agent unless the owner explicitly asks for one." A long unbudgeted cloud-agent loop is what burned tokens on this project; that incident is not recorded in the git history itself, only in this handoff rule and the owner's direction.
- Write findings to files (`docs/*-sources.md`, `data/audio/report.json`, spike reports). Lists first (families, then species names), then per-family research, then a combined list, then per-species media and text. Identify work used the same pattern: a Phase 0 spike with no `src/` changes, owner decisions, then the page (issues 150 and 151).
- Existing compact bird classifiers cannot cover a Kruger-specific list (best found: 186 of 493 species). Train your own on-device model; a 1.7 GB server model (BioCLIP 2) was measured only as an upper bound and was not recommended, to avoid cost and photos leaving the device (`docs/identify-photo-spike.md`).
- Unverified claims were walked back: a female Marsh Warbler song was added and later dropped as contested (commits around PRs #146 / "Drop the contested female Marsh Warbler song"). Length and photo gaps were recorded when no source existed, not filled. Ambiguous Kemp rows were not copied (`docs/population-sources.md`).
- Checks before a PR: `pnpm test`, `pnpm run lint`, `pnpm run kv:dry-run`, `pnpm run check` (`STATE.md`). Coding style: no trailing semicolons, single quotes, `const` arrows (`README.md`).
- Do not close an identify or Live issue from the implementing PR when its "Done when" still needs real-device or tester checks; leave it open and list what testers must try, as PR #187 did for issue 181. Pause rather than iterate on untested phone behaviour.
- Keep a stand-in layout/browser suite that CI can run without model files; skip real-model tests in CI when the `.tflite` files are absent (PR #186). For any live camera or microphone mode, prefer a recorded video (or audio) fixture as issue 181's "Done when" asked, and record it as a gap if the repo has none (PR #187 fed a still test photo because "the repository has no such video"). Write "Not measured" lists into the handoff instead of implying desktop numbers will carry over (`STATE.md`).
