Source: Skinner, J. D. and Chimimba, C. T. (2005). *The Mammals of the Southern African Subregion*, 3rd edition, Cambridge University Press. Read privately by the owner's authority; the book text is not stored in this repository. Page numbers are printed book pages.

Rules followed: fill only fields that were null or logged as gaps; never overwrite a sourced value (conflicts are listed below and left unchanged); own words; ranges only where the book prints a minimum and maximum; Kruger-specific statements only where the book names Kruger or the lowveld; protected species (white and black rhinoceros, Temminck's pangolin) were given no location detail.

## Known leftovers

- Iris colour is not stated in the book for almost any species; those marks stay null.
- Shoulder height is not printed for most small mammals; those slots stay null, as intended.
- Kruger population figures that appear in the book (c. 2005: about 3,300 kudu, 500 eland, 5,800 giraffe) were not entered; they predate the current SANParks counts.
- Suni: the book places it in north-eastern Kruger; the existing status was not changed.
- Tsessebe male tail prints as 40–52 cm in Table 333.1, which looks like a misprint; not entered.
- The bushbuck table (Table 325.1) is for a different subspecies (Chobe); not used for the Kruger form.
- Pages that failed to decode: none blocked a fact. Some table digits on a few pages were unreadable in text and were checked against the page image; where that was not possible the value was not entered.
